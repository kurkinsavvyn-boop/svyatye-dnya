# Святые дня

Подготовка богослужебного списка: календарь «Азбуки веры», редактирование и одностраничный PDF А4 с интервалом 1,5.

## Открыть сайт

https://kurkinsavvyn-boop.github.io/svyatye-dnya/

Версия GitHub Pages работает независимо от ChatGPT: календарь, шрифты и экспорт загружаются с GitHub. Аккаунт OpenAI не нужен. Доступность зависит от сети пользователя.

Календарь содержит предыдущий, текущий и следующий годы. Публикация находится в папке docs. Автоматическое еженедельное обновление подготовлено в .github/pages-workflow.example.yml; для включения нужно перенести его в .github/workflows/pages.yml с доступом GitHub Actions. Если источник недоступен, обновление останавливается, предыдущая публикация остаётся доступна. Нераспознанные записи сохраняются с предупреждением для проверки.

## Разработка

Node.js 22.13+ и pnpm (версия указана в package.json).

- pnpm install --frozen-lockfile
- pnpm test
- pnpm typecheck
- pnpm calendar:prepare
- VITE_STATIC_CALENDAR=true pnpm dev:portable

## Сборка GitHub Pages

VITE_STATIC_CALENDAR=true SITE_BASE_PATH=/svyatye-dnya/ pnpm build:pages

Результат: outputs/standalone/public. Для публикации: VITE_STATIC_CALENDAR=true SITE_BASE_PATH=/svyatye-dnya/ pnpm package:pages, затем git add docs public/calendar, git commit и git push. GitHub Pages настроен на main /docs. Дополнительные годы можно подготовить через CALENDAR_FIRST_YEAR и CALENDAR_LAST_YEAR.

## Серверная версия

Исходная версия Sites использует app/api/calendar/route.ts для загрузки произвольной даты. Самостоятельный Node.js-сервер описан в portable/README.md. GitHub Pages не выполняет серверный код.

## Проверки и ограничения

Регрессионные проверки покрывают имена, лики, ударения источника, сан, соборы и хронологию на сохранённых календарных страницах. Это не богословская экспертиза; перед чтением за богослужением проверьте список. Шрифт PDF — Liberation Serif (лицензия в public/fonts); Word — Times New Roman на компьютере получателя. Поделиться файлом можно в браузерах с Web Share API; скачивание доступно отдельно.

## Редактируемый предпросмотр

После «Подготовить PDF» открывается лист А4, на котором можно менять текст и сокращения ликов. Файл автоматически обновляется после правок; «Скачать» и «Поделиться» используют последнюю версию. Если браузер не поддерживает отправку файлов, кнопка «Поделиться» скачивает PDF и объясняет, как отправить его из приложения.
