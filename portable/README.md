# Святые дня — самостоятельная версия

Этот сайт работает отдельно от ChatGPT. Посетителям не нужен аккаунт OpenAI.

## Размещение

Нужен хостинг с Node.js 22 или новее: VPS, собственный сервер или сервис, поддерживающий Node.js. Обычный GitHub Pages не запускает серверную часть загрузки календаря.

1. Загрузите всю папку на сервер, сохраняя `public/` рядом с `server.mjs`.
2. Запустите `node server.mjs`. По умолчанию сайт слушает порт 8080; другой порт задаётся переменной `PORT`.
3. Настройте постоянный запуск и HTTPS на своём домене через панель хостинга или Nginx.

Установка зависимостей для готовой сборки не требуется. Серверная загрузка обращается напрямую к `https://azbyka.ru/days/`, поэтому серверу нужен доступ к этому источнику.

## Документы

Дата выбирается по новому стилю. Список редактируется перед скачиванием. После подготовки PDF доступно скачивание и, в поддерживающих браузерах на HTTPS, отправка самого файла через системное меню «Поделиться PDF» (Telegram, почта и другие приложения). Создаётся Word, затем его представление преобразуется в PDF: одна страница А4, межстрочный интервал 1,5. Шрифт автоматически уменьшается до размера, при котором текст помещается. Для PDF поставляется Liberation Serif, метрически совместимый с Times New Roman. Word использует Times New Roman, установленный на компьютере.

Неизвестные годы и нераспознанные лики отображаются как записи для проверки. Доступность без VPN зависит от домена, хостинга и сети посетителя; отдельное размещение устраняет зависимость от доменов ChatGPT.
